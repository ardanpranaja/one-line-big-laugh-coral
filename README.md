One funny line of at most 200 characters, written to stand entirely on its own — my entry for the make.fun bounty "One Line, Big Laugh".

## The entry

> I told my therapist I feel invisible. She said she'd check my file — honestly, that's the most attention anyone has paid me all year.

`main.ts` writes that line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader container).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
